# Three synthetic V2 demonstrations

Generated by `CRA_LIVE_MODEL=0 uv run python -m scripts.v2_demo` using a deliberately
scripted client and a tiny invented contract. No live model, corpus download or credentials.

- `success.jsonl`: retrieve a governing clause → calculate a date with its evidence ID → draft → verify → complete.
- `repaired.jsonl`: retrieve → draft an intentionally invalid citation → fail verification → repair → verify → complete.
- `abstained.jsonl`: request a missing clause → observe not_found → abstain.

The client branches on actual tool status and admitted evidence IDs. These traces demonstrate
wiring, counters and failure handling, not learned planning or semantic task success.
Each line includes event identity and a reconstructable state snapshot; its companion
manifest records versions and limits. Normal traces containing contract text stay in the
private gitignored `runs/` directory. Only invented-source examples are checked in here.
