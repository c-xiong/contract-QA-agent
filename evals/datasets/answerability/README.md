# Answerability diagnostic (provisional)

20 tasks, `provisional-generated-answerability-v1`. Expert ContractNLI hypotheses, labels and span indices are transcribed mechanically. The generic question wrapper is AI-authored. These are supplementary pipeline checks, not human-authored capability or resume evidence.

Selection is frozen before running the gate: one sorted NotMentioned and one Entailment hypothesis per registered NDA. Documents belong to the existing corpus; this is not a held-out document benchmark. Empty required_points are not an answer-quality measure. Report behavior counts and independent citation support. Source mappings and hashes are in source-labels.json. Regenerate with scripts/build_answerability_tasks.py.
